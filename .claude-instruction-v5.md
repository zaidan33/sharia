# IMPLEMENTASI V5 — AI Agents

## TIGA FITUR V5 (PRD §16)

### V5.1 Narrative Generation Agent
- Buat `/lib/ai/narrative.ts`
- Fungsi `generateNarrative(computation)`:
  - Output ringkasan bahasa Indonesia: profil pembiayaan, analisis kelayakan, rekomendasi
  - Format naratif: ${usaha} mengajukan ${akad} sebesar ${dana} untuk ${tenor} bulan...
  - Template-based (tanpa LLM), cocok untuk MVP V5
- UI: tab "Narasi" di halaman detail skenario yang menampilkan teks naratif
- Juga generate paragraf untuk tiap metrik: EAR, DSCR, NPV, IRR
- Tombol "Salin narasi" untuk copy ke clipboard

### V5.2 Conversational Copilot
- Halaman baru `/copilot` — chat interface sederhana
- Chat tentang skenario yang sudah ada: "Bagaimana perbandingan skenario A dan B?", "Apa risiko skenario C?"
- Backend: Server Action yang menerima pertanyaan + konteks skenario
- Jawaban dari template responses (rule-based, no LLM):
  - "Bagaimana perbandingan X dan Y?" → tampilkan side-by-side metrik
  - "Apa risiko X?" → highlight DSCR terendah, IRR negatif, dll.
  - "Rekomendasi?" → struktur dengan EAR terendah + DSCR aman
- Simpan riwayat chat di localStorage

### V5.3 Sharia Reasoning Agent
- Halaman baru `/sharia-check` — form untuk cek kepatuhan syariah
- Rule-based checks:
  - Akad murabahah: margin fixed, tidak boleh bunga berjalan → periksa basis flat
  - Akad ijarah: ujrah fixed, transparan → periksa basis flat
  - Akad MMQ: imbal hasil dari sisa porsi bank, bukan bunga → periksa basis efektif
  - Konvensional: flagged sebagai non-syariah dengan disclaimer
  - Riba check: jika EAR > 20%, tampilkan peringatan "Biaya mendekati praktik riba"
- Output: status SYARIAH / TIDAK SESUAI / PERLU KONFIRMASI DPS
- Panel "Konfirmasi DPS" — checklist untuk Dewan Pengawas Syariah (simulasi)
- Simpan hasil pengecekan di tabel baru `sharia_checks`

## ATURAN
1. Jangan rusak fitur MVP + V2–V4 yang sudah ada
2. Semua AI agent rule-based (template), tanpa API call ke LLM
3. UI komponen baru di folder terpisah
4. Commit tiap fitur
5. Test tetap hijau
