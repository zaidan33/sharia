## 4. AI DENGAN DEEPSEEK API

- Buat `/lib/ai/deepseek.ts`
- Client untuk DeepSeek API: `https://api.deepseek.com/v1/chat/completions`
- API key dari `process.env.DEEPSEEK_API_KEY`
- Model: `deepseek-chat` (default)
- Fungsi `askDeepSeek(systemPrompt, userMessage)` untuk chat completion

### Integrasi ke fitur AI yang sudah ada:
- V4.2 Document Extraction: upgrade dari regex ke DeepSeek untuk parsing dokumen lebih akurat
- V5.1 Narrative: upgrade dari template ke DeepSeek untuk narasi lebih natural
- V5.2 Copilot: upgrade dari rule-based ke DeepSeek untuk chat lebih cerdas
- V5.3 Sharia Reasoning: upgrade dari rules ke DeepSeek untuk analisis lebih dalam

Buat fallback: jika `DEEPSEEK_API_KEY` tidak diset, pakai template/rule-based (yang sudah ada).

## 5. FITUR LAPORAN PDF

- Tambah dependency: `@react-pdf/renderer` untuk generate PDF di client
- Atau gunakan `html2canvas` + `jspdf` untuk export dari HTML ke PDF
- Halaman `/scenarios/[id]/report` — laporan PDF lengkap

### Isi Laporan PDF:
1. **Header**: Logo Lihtr UNAIR, judul "Laporan Analisis Kelayakan Pembiayaan", tanggal
2. **Ringkasan Eksekutif**: 1 paragraf naratif (dari V5.1)
3. **Profil Skenario**: tabel identitas (nama, sektor, tujuan, profil risiko)
4. **Struktur Pembiayaan**: tabel (skema, akad, dana, tenor, tingkat, basis)
5. **Indikator Kelayakan**: tabel metrik (EAR, DSCR, NPV, IRR, DER, ROI, BEP) dengan status
6. **Analisis Arus Kas**: grafik arus kas + tabel ringkasan
7. **Analisis Sensitivitas** (dari V2.1): tornado chart
8. **Perbandingan** (dari V2.2): jika ada skenario pembanding
9. **Simpulan & Rekomendasi**: paragraf otomatis
10. **Disclaimer**: batasan model (PRD §11)

Desain PDF: clean, profesional, warna deepteal + hitam, font standar, margin rapi, header/footer tiap halaman.
