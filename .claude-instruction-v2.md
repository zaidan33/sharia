# IMPLEMENTASI V2–V4 — Fitur Lanjutan

Baca `docs/PRD.md` §16 untuk roadmap.

## PRINSIP
1. Jangan rusak fitur MVP yang sudah ada. Semua test harus tetap hijau.
2. Tambah tabel DB baru jika perlu (jangan ubah skema MVP kecuali diperlukan).
3. Engine tetap murni di `/lib/engine/` — no db, no fetch.
4. Uang = `number` bulat rupiah di engine, `bigint` di DB.
5. UI baru di komponen terpisah, jangan modifikasi komponen MVP kecuali untuk integrasi.

## V2 — Sensitivity Engine + Comparator + Terminal Value

### V2.1 Sensitivity Engine
- Tambah `/lib/engine/sensitivity.ts`
- Fungsi `runSensitivity(input, params)`:
  - Vary tiap parameter ±10%, ±20% dari nilai base
  - Output: untuk tiap parameter, hitung dampak pada NPV, IRR, DSCR
  - Kembalikan array `{param, value, npv, irr, dscr}`
- UI: tambah tombol "Analisis Sensitivitas" di halaman detail skenario
- Tornado chart pakai Recharts horizontal bar
- Simpan hasil di tabel baru `sensitivity_results`

### V2.2 Akad Comparator
- Halaman baru `/compare` — pilih 2+ skenario yang sudah ada
- Tampilkan side-by-side: EAR, angsuran, DSCR, NPV, IRR
- Sorot skenario mana yang lebih baik per metrik
- Rekomendasi otomatis: skenario dengan EAR terendah + NPV tertinggi + DSCR aman

### V2.3 Terminal Value
- Tambah opsi "Nilai residu" di form skenario
- Hitung terminal value = CF tahun terakhir × (1 + g) / (r − g)
- Tambahkan ke NPV: NPV_total = NPV + PV_terminal_value
- Tampilkan sebagai komponen terpisah di halaman detail

## V3 — Monte Carlo + Anomaly Detection

### V3.1 Monte Carlo
- Tambah `/lib/engine/monte-carlo.ts`
- Fungsi `runMonteCarlo(input, iterations = 1000)`:
  - Distribusi: pertumbuhan pendapatan ~ Normal(μ, σ), inflasi ~ Normal(μ, σ), dll.
  - Masing-masing iterasi hitung NPV, IRR, DSCR
  - Output: percentiles (5%, 25%, 50%, 75%, 95%), histogram bins
- UI: tombol "Simulasi Monte Carlo" di halaman detail
- Histogram distribusi NPV pakai Recharts
- Simpan hasil di tabel baru `monte_carlo_results`

### V3.2 Anomaly Detection
- Tambah `/lib/engine/anomaly.ts`
- Bandingkan input skenario dengan 20 seed cases yang ada
- Deteksi outlier: pendapatan terlalu rendah untuk sektor tertentu, tenor tidak wajar, dll.
- Tampilkan warning saat membuat skenario baru: "Pendapatan Anda 60% lebih rendah dari rata-rata sektor X"

## V4 — Structure Optimizer + Agents

### V4.1 Structure Optimizer
- Tambah `/lib/engine/optimizer.ts`
- Fungsi `findOptimalStructure(input)`:
  - Coba semua kombinasi: skema (syariah/konvensional), tenor (min-max dengan step), akad
  - Evaluasi tiap kombinasi dengan skor = 0.4 × DSCR + 0.3 × NPV + 0.2 × EAR_rendah + 0.1 × IRR
  - Kembalikan top 5 struktur terbaik
- UI: form "Cari struktur optimal" dengan input kebutuhan dana + kondisi usaha
- Tampilkan tabel peringkat hasil optimasi

### V4.2 Document Extraction Agent (placeholder AI)
- Tambah route `/api/extract` — endpoint POST yang nerima PDF/teks
- Parse teks untuk ekstrak: kebutuhan dana, tenor, skema, dll.
- Prefill form skenario baru dengan hasil ekstraksi
- Untuk MVP V4: parse teks biasa dulu (regex-based), AI integration menyusul

### V4.3 Assumption Calibration Agent
- Tambah `/lib/engine/calibrator.ts`
- Fungsi `calibrate(sector, amount, tenor)`:
  - Bandingkan dengan seed cases di sektor yang sama
  - Sarankan rentang wajar untuk: pertumbuhan pendapatan, inflasi biaya, margin kontribusi
- Tampilkan di form sebagai saran (bisa ditimpa pengguna)
